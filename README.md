# LUVO — сайт-визитка

Готовый статический сайт для GitHub Pages.

## Файлы
- `index.html` — тексты, каталог, тарифы и контакты.
- `styles.css` — адаптивный дизайн.
- `script.js` — мобильное меню.

## Перед публикацией
В `index.html` найдите `https://t.me/` и замените на реальную ссылку Telegram, например `https://t.me/username`. Проверьте цены и описания.

## Публикация с телефона
1. Создайте публичный репозиторий GitHub, например `luvo-site`.
2. Распакуйте архив на телефоне.
3. Загрузите файлы `index.html`, `styles.css`, `script.js` в корень репозитория через **Add file → Upload files**.
4. Откройте **Settings → Pages**.
5. Выберите **Deploy from a branch**, ветку `main`, папку `/ (root)`, нажмите Save.
6. После публикации GitHub покажет адрес сайта.

## Изменение цен
Цены находятся в `index.html` в блоке `packages`. Их можно заменить через Edit на GitHub, не меняя CSS и дизайн.
